# Yousef Ali — Portfolio

A small site with links to web apps I've built. The portfolio itself uses React, TypeScript and Vite.

Most of my work is in interactive interfaces and full-stack web development: connecting React frontends to APIs, handling accounts and data, and getting sites ready to deploy.

## Projects

**[Multilingual CMS](https://github.com/yousef-iq1/multilingual-cms)**  
A publishing app with a protected editor, article workflows, authentication and a PostgreSQL backend. React, TypeScript, Express and Supabase.

**[Seen It](https://github.com/yousef-iq1/Seen-it)**  
A movie and TV discovery app with swipe-based recommendations, accounts, shareable lists and an Arabic/English interface. React 19, Next.js and Supabase.

**[IQD Market Tracker](https://github.com/yousef-iq1/iqd-market-tracker)**  
An Iraqi dinar dashboard with API-backed exchange rates, charts and a converter. React, TypeScript, Express and Recharts.

**[Arabic Search Context Lab](https://github.com/yousef-iq1/arabic-search-context-lab)**  
A comparison of the same Arabic search query across Baghdad, Riyadh, Cairo and Casablanca. Built with Next.js and SerpApi.

## Running this site

```bash
npm install
npm run dev
```

Production build: `npm run build`.
